## Задача 3.6. Одинаковые ли все цифры
### Текст задачи

Необходимо реализовать метод таким образом, чтобы он возвращал `true`, если все цифры числа `x` одинаковы.

### Алгоритм решения
1. Запомнить последнюю цифру числа.
2. В цикле `while` сравнивать каждую цифру с запомненной.
3. Если встретилась отличная — вернуть `false`.
4. Отбрасывать последнюю цифру делением на 10.
5. Если цикл завершился — вернуть `true`.

### Код метода
```java
public boolean equalNum(int x) {
    int lastDigit = x % 10;
    while (x > 0) {
        int currentDigit = x % 10;
        if (currentDigit != lastDigit) {
            return false;
        }
        x = x / 10;
    }
    return true;
}
```

Необходимо реализовать метод таким образом, чтобы он возвращал индекс последнего вхождения числа `x` в массив `arr`. Если числа нет — вернуть `-1`.

### Алгоритм решения
1. Пройти по массиву с конца.
2. Первое совпадение — последнее вхождение, вернуть индекс.
3. Если дошли до начала — вернуть `-1`.

### Код метода
```java
public int findLast(int[] arr, int x) {
    for (int i = arr.length - 1; i >= 0; i--) {
        if (arr[i] == x) {
            return i;
        }
    }
    return -1;
}
```

## Задача 4.5. Вставка массива в массив
### Текст задачи
Дана сигнатура метода: `public int[] add(int[] arr, int[] ins, int pos);`
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, в котором в позицию `pos` вставлены элементы массива `ins`.

### Алгоритм решения
1. Создать массив `result` длиной `arr.length + ins.length`.
2. Скопировать `arr[0..pos-1]` в начало `result`.
3. Скопировать `ins` начиная с позиции `pos`.
4. Скопировать остаток `arr` (с `pos` до конца) после `ins`.
5. Вернуть `result`.

### Код метода
```java
public int[] add(int[] arr, int[] ins, int pos) {
    int[] result = new int[arr.length + ins.length];
    for (int i = 0; i < pos; i++) {
        result[i] = arr[i];
    }
    for (int i = 0; i < ins.length; i++) {
        result[pos + i] = ins[i];
    }
    for (int i = pos; i < arr.length; i++) {
        result[i + ins.length] = arr[i];
    }
    return result;
}
```

### Текст задачи
Дана сигнатура метода: `public int[] concat(int[] arr1, int[] arr2);`
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив, где сначала идут элементы `arr1`, затем `arr2`.

### Алгоритм решения
1. Создать массив `result` длиной `arr1.length + arr2.length`.
2. Скопировать `arr1` в начало.
3. Скопировать `arr2` после `arr1`.
4. Вернуть `result`.

### Код метода
```java
public int[] concat(int[] arr1, int[] arr2) {
    int[] result = new int[arr1.length + arr2.length];
    for (int i = 0; i < arr1.length; i++) {
        result[i] = arr1[i];
    }
    for (int i = 0; i < arr2.length; i++) {
        result[arr1.length + i] = arr2[i];
    }
    return result;
}
```

## Задача 4.10. Удаление негатива
### Текст задачи
Дана сигнатура метода: `public int[] deleteNegative(int[] arr);`
Необходимо реализовать метод таким образом, чтобы он возвращал новый массив со всеми элементами массива `arr` кроме отрицательных.

### Алгоритм решения
1. Первый проход: посчитать количество неотрицательных элементов.
2. Создать массив `result` размером `count`.
3. Второй проход: скопировать неотрицательные элементы.
4. Вернуть `result`.

### Код метода
```java
public static int[] deleteNegative(int[] arr) {
    int count = 0;
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] >= 0) {
            count++;
        }
    }
    int[] result = new int[count];
    int j = 0;
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] >= 0) {
            result[j] = arr[i];
            j++;
        }
    }
    return result;
}
```
